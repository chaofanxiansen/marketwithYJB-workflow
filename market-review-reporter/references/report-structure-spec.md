## 二、各板块内容要点

### 一、今日A股复盘
- **指数展示：** 上证指数 / 深证成指 / 创业板指，只显示涨跌幅（如 +1.41%），**不显示点位**
- **市场概况：** 成交额（亿元）、较上日量能变化、上涨个股家数
- **领涨板块：** 涨幅居前 2-4 个板块
- **领跌板块：** 跌幅居前 2-4 个板块

### 二、外盘与联动
- **美股：** 道琼斯 / 标普500 / 纳斯达克，显示周涨跌百分比，关键点位可保留（如 53732.41）
- **韩股：** KOSPI 走势与驱动逻辑（半导体、外资动向等）
- **联动推演：** 隔夜外盘对明日 A股开盘的映射判断

### 三、消息面梳理
- 每条消息标注：【利好】/【利空】/【中性】+ 来源 + 一句话影响路径
- 政策类区分"已落地"与"预期/传闻"
- 3-5 条为宜，覆盖：A股政策、外盘、领涨板块催化、盘后突发

### 四、市场情绪与强弱判断
- **市场温度：** 偏热 / 中性 / 偏冷（一句话依据）
- **判断依据：** 量能 + 涨跌停比 + 板块效应 + 指数分化
- **核心逻辑：** 一段话概括当日市场主线

### 五、养基宝持仓分析与调仓建议
- 见第三节强制规范
- 调仓建议**逐基金**给出：操作方向 + 依据 + 幅度约束（如"单次不超过总仓位5%"）

### 六、风险提示
- 数据时效性、消息不确定性、持仓相关风险、汇率风险
- 与用户持仓直接相关的具体风险优先

## 三、养基宝持仓展示规范（强制）

> 以下为固定口径，**每次生成报告必须遵守**：

1. **账户范围：** 只展示「大A」和「忠诚」两个账户，**隐藏「支付宝」账户**（含其所有持仓与金额）
2. **金额禁令：** 全篇**不出现任何具体金额数字**——不显示市值、不显示盈亏金额、不显示持仓成本
3. **只显示比例：**
   - 账户总盈亏：只显示盈亏比例，卡片 **2 张一排**（2×2 网格布局，`.grid-2` 类）
   - 每只基金：只显示「本日涨跌」和「收益率」两个百分比
4. **持仓明细表列：** 账户 | 基金名称 | 代码 | 本日涨跌 | 收益率
   - 本日涨跌 = 当日盘中估值涨幅（`vgszzl`），QDII 标注为估算值
   - 收益率 = 累计收益率（持有盈亏比例）
5. **表注：** 表格下方注明"本日涨跌为当日盘中估值涨幅，QDII 基金为估算值，最终以官方净值为准"
6. **调仓建议：** 按基金逐一列出（编号），每只标注所属账户（大A/忠诚），操作必须带依据与幅度约束

## 六、页面格式规范（HTML 展示）

> 整页 HTML 按 Hana 美学规范生成（暖纸、克制、衬线），关键 token 如下：

**配色：**
- 页面底色 `#F8F4ED`（暖纸），卡片底色 `#FCFAF5`，绝不用纯白大底
- 唯一强调色 `#537D96`（青灰蓝），占比 ≤ 5%，只做点睛
- 文字：主文 `#3B3D3F` / 次级 `#6B6F73` / 弱化 `#8E9196`，不用纯黑
- 语义色：涨=红 `#8B3A3A`、跌=绿 `#7BAE7F`（A股习惯），低饱和克制
- 线条：发丝细线暖调 `rgba(122,96,88,.18)`，用线+留白分区，不用实色块堆叠

**字体：**
- 正文/标题：`'EB Garamond','Noto Serif SC','Songti SC','SimSun',serif`（衬线）
- 数字/表格：`'JetBrains Mono',monospace`，`font-variant-numeric:tabular-nums` 对齐
- 功能性文字（标签/表头）：`system-ui,'PingFang SC',sans-serif`
- 字重仅 400/500，层级靠字号+明度+字距，不靠加粗

**排版层级：**
- h1 1.6rem 页面主标题 / h2 1.25rem 板块标题（左竖线 `border-left:2px solid #537D96`）/ h3 1.05rem 子标题 / 正文 16px 行高 1.7
- 指数与百分比用大数字卡片（stat-value），涨跌幅直接着色
- 持仓明细用表格（fund-table），表头浅垫色、数字等宽对齐
- 调仓建议用左侧竖线强调块（advice-box，青灰蓝底浅垫）
- 账户总盈亏卡片 **2 张一排**（`.grid-2`：2×2 网格）

**布局：**
- 单栏容器，最大宽 900px，居中，卡片内边距 1.5-3rem
- 移动端 768px 断点收缩内边距、网格变两列

**报告页头：**
- 标题「📊 每日市场复盘报告」+ 副标题「A股 + 外盘联动分析与持仓建议」+ 日期（等宽字体）

**页脚免责：**
- 灰色小字：数据来源 + "仅供信息参考与决策辅助，不构成投资建议"
