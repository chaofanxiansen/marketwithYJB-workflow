# Market Review Reporter

复盘工作流的第二步：把硬数据变成一份有温度、可读的整页 HTML 报告。输入是数据，输出是一个自包含的 HTML 文件，六个板块顺序固定。

## 输入来源

| 数据 | 来源 |
|------|------|
| A股指数 / 量能 / 板块 | market-data-collector 脚本 + web_search 兜底 |
| 美股 / 韩股 | market-data-collector 脚本 + web_search |
| 持仓数据 | 养基宝 yjb_fetch.py（--raw 取 vgszzl 估值涨幅） |
| 消息面 | market-data-collector 的 web_search 结果 |

## 报告结构（六个板块，顺序固定）

| 序号 | 板块 | 内容 |
|------|------|------|
| 一 | 今日A股复盘 | 三大指数涨跌幅卡片（不显示点位）、市场概况、领涨/领跌板块、市场广度 |
| 二 | 外盘与联动 | 美股（周涨跌+点位）、韩股 KOSPI、港股亚太、联动推演 |
| 三 | 消息面梳理 | 利好/利空/中性分类，每条附来源与影响路径 |
| 四 | 市场情绪与强弱判断 | 市场温度、判断依据（数据可追溯）、核心逻辑 |
| 五 | 养基宝持仓分析与调仓建议 | 账户总盈亏 + 持仓明细表 + 逐基金调仓建议（见强制规范） |
| 六 | 风险提示 | 数据时效、消息不确定、持仓相关、汇率风险，至少四条 |

## 养基宝持仓展示规范（强制）

1. **账户范围**：只展示「大A」和「忠诚」两个账户，**隐藏「支付宝」账户**（含其所有持仓与金额）
2. **金额禁令**：全篇不出现任何具体金额数字——不显示市值、不显示盈亏金额、不显示持仓成本
3. **只显示比例**：
   - 账户总盈亏：只显示盈亏比例，卡片 **2 张一排**（2×2 网格，`.grid-2` 类，大A今日/累计 + 忠诚今日/累计）
   - 每只基金：只显示「本日涨跌」和「收益率」两个百分比
4. **持仓明细表列**：账户 | 基金名称 | 代码 | 本日涨跌 | 收益率
   - 本日涨跌 = 当日盘中估值涨幅（`vgszzl`），QDII 标注为估算值
   - 收益率 = 累计收益率（持有盈亏比例）
5. **表注**：表格下方注明"本日涨跌为当日盘中估值涨幅，QDII 基金为估算值，最终以官方净值为准"
6. **调仓建议**：按基金逐一列出（编号），每只标注所属账户，操作必须带依据与幅度约束（如"单次不超过总仓位5%"）

## Hana HTML 美学规范（关键 token）

**配色：**
- 页面底色 `#F8F4ED`（暖纸），卡片 `#FCFAF5`，绝不用纯白大底
- 唯一强调色 `#537D96`（青灰蓝），占比 ≤ 5%
- 文字：主文 `#3B3D3F` / 次级 `#6B6F73` / 弱化 `#8E9196`，不用纯黑
- 语义色（A股习惯）：涨=红 `#8B3A3A`、跌=绿 `#7BAE7F`，低饱和克制
- 线条：发丝细线暖调 `rgba(122,96,88,.18)`

**字体：**
- 正文/标题：`'EB Garamond','Noto Serif SC','Songti SC','SimSun',serif`
- 数字/表格：`'JetBrains Mono',monospace`，`font-variant-numeric:tabular-nums` 对齐
- 功能性文字：`system-ui,'PingFang SC',sans-serif`
- 字重仅 400/500，层级靠字号+明度+字距

**排版：**
- h1 2rem 主标题 / h2 1.25rem 板块标题（`border-left:3px solid #537D96`）/ h3 1.05rem / 正文 16px 行高 1.7
- 指数与百分比用大数字卡片（stat-value），涨跌幅直接着色
- 持仓明细用表格（fund-table），表头浅垫色、数字等宽
- 调仓建议用左侧竖线强调块（advice-box）
- 单栏容器最大宽 900px 居中，卡片内边距 1.5-3rem
- 移动端 768px 断点收缩内边距、网格变两列

**页面骨架：**
- 右上角「历史」下拉按钮（SVG 时钟图标），列出所有已发布报告，当前页高亮 `.current`
- header 用 flex 左右布局：左标题+副标题+日期，右历史按钮
- 页脚灰色小字免责：数据来源 + "仅供信息参考与决策辅助，不构成投资建议"

## 报告头信息

```
📊 每日市场复盘报告
A股 + 外盘联动分析与持仓建议
2026年8月X日 · 周X        [等宽字体，JetBrains Mono]
```

## 输出与交付

- 生成完整自包含 HTML（内联 CSS，无外部依赖）
- 文件命名：最新版 `index.html`；同时保存日期归档 `2026-08-XX.html`
- 写入本地备份目录 `D:\HanakoDate\deploy_reports\`
- 部署步骤交给 market-report-deployer skill

## 判断要点

- 情绪极热（涨停 > 150、创业板单日 > 5%）时追涨建议要格外谨慎，宁可提示"不追高、等回调"
- 权重搭台题材唱戏（指数微涨但题材普涨）与指数逼空（指数大涨但广度一般）是两种格局，结论不同
- 海外映射类行情要评估持续性：趋势启动还是情绪脉冲
- 数据口径与搜索交叉验证：脚本指数与新闻收盘报道差异超 0.2 个百分点时，以脚本为准并在报告说明
