# Market Data Collector

复盘工作流的第一步：把"看盘"变成确定性数字。本 skill 通过程序化接口获取 A股与全球市场行情，产出可供报告引用的结构化硬数据。**硬数据不靠记忆、不靠转述，必须跑脚本拿到。**

## 输出目标

一段结构化的数据快照，包含以下全部区块（拿不到的明确标注，不许编造）：

```
===== A-SHARE INDICES =====
上证指数 / 深证成指 / 沪深300 / 创业板指 / 科创50：收盘价、涨跌幅、成交额
===== MARKET BREADTH =====
沪市/深市：上涨 / 下跌 / 平盘家数
===== LIMIT UP / DOWN =====
涨停总数 / 跌停总数
===== GLOBAL INDICES =====
道琼斯 / 标普500 / 纳斯达克 / 恒生 / 日经225 / 韩国KOSPI / 台湾加权 / 英/德/法
===== FX & COMMODITIES =====
美元指数 / USDCNH / COMEX黄金 / WTI原油 / COMEX白银
===== SECTOR FUND FLOW =====
行业板块净流入 TOP8 / 净流出 TOP5（板块名、涨跌幅、主力净流入额）
===== CONCEPT GAINERS =====
概念板块涨幅 TOP10
```

## 执行步骤

### 1. 运行主脚本

PowerShell（Windows 环境默认，零依赖）：

```powershell
& <skill目录>/scripts/market_data.ps1
```

- 复盘历史某天时传日期参数：`& market_data.ps1 -Date 20260803`
- 脚本内置 HTTPS→HTTP 自动降级（东财指数/板块/新浪商品），板块 clist 另有 push2delay 备用域名；任一数据源失败不会拖垮整体
- **脚本失败或部分缺失时**，用 `web_search` 兜底补齐关键指数（至少上证、深成指、创业板、恒生、美股三大指数），并注明数据来源

### 2. 补消息面（web_search）

按四个方向搜索，每个方向 2-4 条：

1. **今日/盘后 A股消息**：政策、央行操作（MLF/LPR/逆回购）、监管表态、重要会议
2. **隔夜与最新外盘**：美联储讲话、美债收益率、美股财报、地缘事件
3. **领涨板块催化**：今天涨最多的板块为什么涨（来自脚本数据）
4. **盘后突发**：个股公告、减持、业绩预告、海外盘后异动

消息面每条归类【利好】/【利空】/【中性】，标注来源与时间。政策类区分"已落地"和"预期/传闻"。

## 数据解读规则

- **成交额单位**为元，换算亿除以 1e8（保留一位小数）。两市合计 = 上证 amount + 深证 amount
- **量能分档**：两市合计 > 2万亿 = 放量活跃；1.4~2万亿 = 正常；< 1.2万亿 = 缩量
- **情绪温度计**：涨停 > 100 且跌停 < 10 = 偏热；涨停 < 40 或跌停 > 30 = 偏冷；涨跌停比是核心指标
- **涨跌家数**：脚本分沪/深两个市场返回，做全市场统计时相加得约数；与新闻口径（含北交所）可能差几十到一两百，报告里写"约"并注明
- **板块资金流 net inflow** 单位是元，换算成亿
- **北向资金**：2024年8月起交易所不再实时披露北向净买入，只有成交额。如实说明现状，不要编造净买入数字
- **涨停/跌停家数若异常小**：先确认日期参数——交易日用当日，周末/节假日复盘上一交易日。A股 15:00 收盘后跑即当日收盘数据
- **美股数据**为最新一个完整交易日（美东时间）。北京时间白天看到的是隔夜美股收盘，晚上是当日盘中/收盘，报告里写清时间口径

## 兜底与降级

| 场景 | 处理 |
|------|------|
| 东财 HTTPS 挂 | 脚本自动切 HTTP，再挂切 push2delay 域名 |
| 新浪商品挂 | 脚本自动降级 HTTP |
| 脚本全灭 | web_search 补齐关键指数并注明来源 |
| A50期货/美债收益率/BTC | 接口常无数据，用 web_search 兜底 |
| 北向净买入 | 不公开，用两融余额、ETF申赎等替代观察（需搜索） |

## 脚本文件

- `scripts/market_data.ps1` — 主脚本（PowerShell 5.1，ASCII-only，HTTPS→HTTP 自动降级）
- `scripts/fetch_today_full.py` — Python 备用路径（东财+腾讯双源），脚本命名含日期可改

## 铁律

1. 数字先于观点：任何结论前先跑脚本拿真实行情，禁止凭印象编造点位、涨幅、成交额
2. 脚本拿不到的明确标注"以搜索为准"或"该数据已不公开"，不用推测数字填充
3. 每条消息标注来源与可信度：官方公告/央行/监管 = 高可信；权威财经媒体 = 中高；自媒体/社交平台 = 低可信，标注"传闻待证实"
